## 5. Gemini

- 모델: **`gemini-3.5-flash` (실사용)** — 요구사항은 "Gemini 3.8 Flash"였으나 아래 이유로 변경.
- **측정 결과 (동일 프롬프트, `thinkingBudget: 0`)**:
  | 모델 | 응답 시간 |
  |---|---|
  | `gemini-3.8-flash` | **33.9초** (간헐 60초+) |
  | `gemini-flash-latest` | 40초+ (타임아웃) |
  | **`gemini-3.5-flash`** | **1.6초** |
- `gemini-3.8-flash`는 Vercel 함수 제한(60초)을 자주 넘겨 AI 칸이 비는 문제 → **빠른 `gemini-3.5-flash`로 확정**(사용자 승인).
- `generationConfig.thinkingConfig.thinkingBudget = 0` 으로 추론을 끔.
- `responseMimeType: "application/json"` 로 JSON 강제.
- 간헐적으로 `503 UNAVAILABLE`(high demand) 발생 → 앱에서는 **자동 재시도 없이** 실패 처리(AI 칸 비움).
- 예시 검증 결과(가상 입력 "빈 강의실 실시간 안내 봇"):
  ```json
  {"category":"campus","score":4,
   "score_reason":"실현가능성과 기대효과가 높으나 창의성은 다소 평이함",
   "review":"... (4문장, 강점2·보완2)"}
  ```
  → `valid category: true`, `valid score: true`
- 테스트 스크립트: `scripts/test-gemini.mjs`, `scripts/test-gemini-review.mjs`
